# HopeDB Database Setup

## Requirements
- PostgreSQL
- pgAdmin
- Git

## Database Setup
1. Install PostgreSQL.
2. Open pgAdmin.
3. Create a database named hopedb.

## Run Migrations
1. Open the project folder.
2. Run the migration script.
3. Enter your PostgreSQL password when prompted.

## Verify Setup
Open pgAdmin and check that the required
HopeDB tables have been created.

## Troubleshooting
- Check your PostgreSQL server.
- Check your database name.
- Check your username and password.
